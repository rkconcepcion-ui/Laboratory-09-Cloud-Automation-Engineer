# Automation Research

## 1. Bash Script

A Bash script is a text file containing Linux commands that can be executed together to automate tasks. The `#!/bin/bash` line, called the shebang, tells the operating system to use Bash to interpret the script.

## 2. Variables

Variables store values such as folder paths or filenames so they can be reused throughout a script. For example, `$BACKUP_DIR` allows a programmer to change the backup location in one place instead of editing every command that uses that path.

## 3. Cron Job

A cron job is a scheduled task in Linux that runs a command or script at a specified time or interval. It is useful in cloud operations because it automates repetitive tasks, such as backups, without requiring an administrator to run them manually each time.
